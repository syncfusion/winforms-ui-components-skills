# Getting Started with GridRecordNavigationControl

This guide covers installation, setup, and basic implementation of the Syncfusion GridRecordNavigationControl in Windows Forms applications.

## Assembly Deployment

Before using GridRecordNavigationControl, you must add the required assemblies to your project.

### Required Assemblies

| Assembly | Description |
|----------|-------------|
| **Syncfusion.Grid.Windows.dll** | Contains classes that handle all UI operations, fundamentals, and base classes of the GridRecordNavigationControl |
| **Syncfusion.Shared.Base.dll** | Contains style-related properties and various editor controls used in the GridRecordNavigationControl |

### Adding Assembly References

1. Right-click your project in Solution Explorer
2. Select "Add Reference"
3. Browse to your Syncfusion installation directory
4. Add both required assemblies
5. Click OK

**Typical Installation Path:**
```
C:\Program Files (x86)\Syncfusion\Essential Studio\<Version>\precompiledassemblies\<.NET Version>\
```

## Creating GridRecordNavigationControl Through Designer

The designer approach is **recommended** for initial setup as it generates proper initialization code automatically.

### Important: Correct Drop Order

⚠️ **Critical:** To get proper initialization code generated by the designer, you must follow this specific order:

1. **First:** Drag and drop GridRecordNavigationControl onto the form
2. **Second:** Drag the grid control (GridControl or GridDataBoundGrid) directly **INTO** the GridRecordNavigationControl

**Do NOT drop the grid onto the form itself** - it must be dropped directly into the navigation control.

### Step-by-Step Designer Setup

#### Step 1: Add GridRecordNavigationControl to Form

1. Open your form in the Visual Studio Designer
2. Locate **GridRecordNavigationControl** in the Toolbox
   - If not visible, ensure Syncfusion assemblies are referenced
3. Drag GridRecordNavigationControl from toolbox to your form
4. Position it where desired on the form


#### Step 2: Size and Position the Control

1. Select the GridRecordNavigationControl
2. Resize to desired dimensions using handles
3. Use Properties window to set exact Location and Size if needed

#### Step 3: Add Grid Control

1. Locate **GridDataBoundGrid** or **GridControl** in the Toolbox
2. Drag the grid control and drop it **directly onto the GridRecordNavigationControl**
   - **Not onto the form!**
   - The grid must be a child of the navigation control
3. The grid will be nested inside the navigation control


#### Step 4: Configure Data Source (For GridDataBoundGrid)

1. Select the GridDataBoundGrid control
2. In Properties window, find **DataSource** property
3. Set to an appropriate data source object:
   - DataTable
   - BindingSource
   - DataSet table
   - Any object implementing IList or IListSource


#### Step 5: Run the Application

1. Build the solution (F6)
2. Run the application (F5)
3. The GridRecordNavigation control will display with navigation bar at bottom


### Designer-Generated Code

When you follow the correct drop order, the designer generates initialization code like this:

```csharp
private Syncfusion.Windows.Forms.Grid.GridRecordNavigationControl recordNavigationControl1;
private Syncfusion.Windows.Forms.Grid.GridDataBoundGrid gridDataBoundGrid1;

private void InitializeComponent()
{
    this.recordNavigationControl1 = new Syncfusion.Windows.Forms.Grid.GridRecordNavigationControl();
    this.gridDataBoundGrid1 = new Syncfusion.Windows.Forms.Grid.GridDataBoundGrid();
    
    // GridRecordNavigationControl
    this.recordNavigationControl1.Location = new System.Drawing.Point(12, 12);
    this.recordNavigationControl1.Size = new System.Drawing.Size(760, 400);
    this.recordNavigationControl1.Controls.Add(this.gridDataBoundGrid1);
    
    // GridDataBoundGrid
    this.gridDataBoundGrid1.DataSource = this.myDataSource;
    
    // Form
    this.Controls.Add(this.recordNavigationControl1);
}
```

## Creating GridRecordNavigationControl Through Code

You can create the control entirely through code without using the designer.

### Minimal Code Example with GridControl

```csharp
using Syncfusion.Windows.Forms.Grid;
using System.Drawing;
using System.Windows.Forms;

public partial class Form1 : Form
{
    private GridRecordNavigationControl recordNavigationControl1;
    private GridControl gridControl1;
    
    public Form1()
    {
        InitializeComponent();
        SetupNavigationControl();
    }
    
    private void SetupNavigationControl()
    {
        // Create GridRecordNavigationControl
        this.recordNavigationControl1 = new GridRecordNavigationControl();
        this.recordNavigationControl1.Location = new Point(32, 48);
        this.recordNavigationControl1.MaxLabel = "of 1000";
        this.recordNavigationControl1.MaxRecord = 1000;
        this.recordNavigationControl1.NavigationBarWidth = 237;
        this.recordNavigationControl1.Size = new Size(520, 256);
        this.recordNavigationControl1.SplitBars = Syncfusion.Windows.Forms.DynamicSplitBars.Both;
        
        // Create GridControl
        this.gridControl1 = new GridControl();
        this.gridControl1.ColCount = 16;
        this.gridControl1.NumberedRowHeaders = false;
        this.gridControl1.RowCount = 1000;
        
        // Add the grid to the Record Navigation control
        this.recordNavigationControl1.Controls.Add(this.gridControl1);
        
        // Add the Record Navigation control to the form
        this.Controls.Add(this.recordNavigationControl1);
    }
}
```

### Code Example with GridDataBoundGrid

```csharp
using Syncfusion.Windows.Forms.Grid;
using System.Data;
using System.Drawing;

private void SetupDataBoundNavigation()
{
    // Create GridRecordNavigationControl
    var navControl = new GridRecordNavigationControl();
    navControl.Location = new Point(20, 20);
    navControl.Size = new Size(700, 450);
    navControl.NavigationBarWidth = 250;
    
    // Create GridDataBoundGrid
    var dataGrid = new GridDataBoundGrid();
    
    // Create and bind data source
    DataTable dt = CreateDataTable(); // Your data creation method
    dataGrid.DataSource = dt;
    
    // Configure navigation based on data
    navControl.MaxRecord = dt.Rows.Count;
    navControl.MaxLabel = $"of {dt.Rows.Count}";
    
    // Add grid to navigation control
    navControl.Controls.Add(dataGrid);
    
    // Add to form
    this.Controls.Add(navControl);
}

private DataTable CreateDataTable()
{
    DataTable dt = new DataTable("Employees");
    dt.Columns.Add("ID", typeof(int));
    dt.Columns.Add("Name", typeof(string));
    dt.Columns.Add("Department", typeof(string));
    
    for (int i = 1; i <= 1000; i++)
    {
        dt.Rows.Add(i, $"Employee {i}", $"Dept {i % 10}");
    }
    
    return dt;
}
```

## Basic Configuration

### Key Properties to Set

When setting up GridRecordNavigationControl, configure these essential properties:

```csharp
// Record count configuration
recordNavigationControl1.MaxRecord = totalRecords;
recordNavigationControl1.MaxLabel = $"of {totalRecords}";

// Navigation bar appearance
recordNavigationControl1.NavigationBarWidth = 250; // Width in pixels

// Split bars for resizing
recordNavigationControl1.SplitBars = DynamicSplitBars.Both;

// Size and position
recordNavigationControl1.Location = new Point(x, y);
recordNavigationControl1.Size = new Size(width, height);
```

### Property Descriptions

| Property | Type | Purpose |
|----------|------|---------|
| `MaxRecord` | int | Total number of records in the dataset |
| `MaxLabel` | string | Label text showing record count (e.g., "of 1000") |
| `NavigationBarWidth` | int | Width of the navigation bar area in pixels |
| `SplitBars` | DynamicSplitBars | Enables split bars for resizing (None, Both, Horizontal, Vertical) |

## Complete Working Example

Here's a complete example that creates a functional navigation control with sample data:

```csharp
using System;
using System.Data;
using System.Drawing;
using System.Windows.Forms;
using Syncfusion.Windows.Forms.Grid;

namespace NavigationExample
{
    public partial class MainForm : Form
    {
        private GridRecordNavigationControl navigationControl;
        private GridDataBoundGrid dataGrid;
        
        public MainForm()
        {
            InitializeComponent();
            InitializeNavigationControl();
            LoadData();
        }
        
        private void InitializeNavigationControl()
        {
            // Create navigation control
            navigationControl = new GridRecordNavigationControl
            {
                Location = new Point(10, 10),
                Size = new Size(780, 550),
                NavigationBarWidth = 240,
                SplitBars = DynamicSplitBars.Both
            };
            
            // Create data grid
            dataGrid = new GridDataBoundGrid();
            
            // Add grid to navigation control
            navigationControl.Controls.Add(dataGrid);
            
            // Add navigation control to form
            this.Controls.Add(navigationControl);
        }
        
        private void LoadData()
        {
            // Create sample data
            DataTable employees = new DataTable("Employees");
            employees.Columns.Add("EmployeeID", typeof(int));
            employees.Columns.Add("FirstName", typeof(string));
            employees.Columns.Add("LastName", typeof(string));
            employees.Columns.Add("Department", typeof(string));
            employees.Columns.Add("Salary", typeof(decimal));
            
            // Add sample records
            for (int i = 1; i <= 500; i++)
            {
                employees.Rows.Add(
                    i,
                    $"FirstName{i}",
                    $"LastName{i}",
                    $"Department{i % 10}",
                    30000 + (i * 100)
                );
            }
            
            // Bind to grid
            dataGrid.DataSource = employees;
            
            // Update navigation control
            navigationControl.MaxRecord = employees.Rows.Count;
            navigationControl.MaxLabel = $"of {employees.Rows.Count}";
        }
    }
}
```

## Troubleshooting

### Grid Not Appearing in Navigation Control

**Problem:** Grid is positioned outside the navigation control area.

**Solution:** Ensure you dropped the grid INTO the navigation control in designer, or added it to the Controls collection in code:
```csharp
navigationControl.Controls.Add(gridControl); // Correct
this.Controls.Add(gridControl); // Wrong - adds to form instead
```

### Navigation Bar Not Visible

**Problem:** Navigation bar is too narrow or hidden.

**Solution:** Set NavigationBarWidth property:
```csharp
recordNavigationControl1.NavigationBarWidth = 250;
```

### Record Count Not Updating

**Problem:** MaxLabel shows incorrect count.

**Solution:** Update MaxRecord and MaxLabel when data changes:
```csharp
recordNavigationControl1.MaxRecord = newRowCount;
recordNavigationControl1.MaxLabel = $"of {newRowCount}";
```

## Best Practices

✅ **Do:**
- Use designer for initial setup - it generates correct code
- Drop grid INTO navigation control, not onto form
- Update MaxRecord/MaxLabel when data changes
- Set appropriate NavigationBarWidth for your UI

❌ **Don't:**
- Drop grid onto form separately from navigation control
- Forget to add required assembly references
- Leave MaxRecord at 0 or incorrect value
- Nest multiple grids in one navigation control
