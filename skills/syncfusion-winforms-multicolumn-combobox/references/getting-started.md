# MultiColumnComboBox

## Getting Started

The `MultiColumnComboBox` control can be created programmatically through code as detailed below.

### Step 1: Include the Required Namespace

```csharp
using Syncfusion.Windows.Forms.Tools;
```

### Step 2: Create and Add MultiColumnComboBox

Create an instance of `MultiColumnComboBox` and add that instance to the form.

```csharp
private Syncfusion.Windows.Forms.Tools.MultiColumnComboBox multiColumnComboBox1;

this.multiColumnComboBox1 = new Syncfusion.Windows.Forms.Tools.MultiColumnComboBox();
this.Controls.Add(this.multiColumnComboBox1);
```

### Step 3: Bind to Data Source

After creating `MultiColumnComboBox`, you can bind it using a data source. Refer to DataBinding.
