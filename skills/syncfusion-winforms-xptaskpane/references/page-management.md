## Page Title Configuration

Set the title text displayed in the page header:

```csharp
xpTaskPage1.Title = "First Task";
xpTaskPage2.Title = "Second Task";
xpTaskPage3.Title = "Third Task";
```

```vb
xpTaskPage1.Title = "First Task"
xpTaskPage2.Title = "Second Task"
xpTaskPage3.Title = "Third Task"
```

**Title Use Cases:**
- Display section names
- Show current workflow step
- Indicate page purpose
- Provide user guidance

The title appears in the page header and in the dropdown menu when users browse pages.

## Layout Name

Each task page has a unique identifier called LayoutName:

```csharp
// Default names are auto-generated
xpTaskPage1.LayoutName = "Card1";  // First page
xpTaskPage2.LayoutName = "Card2";  // Second page
xpTaskPage3.LayoutName = "Card3";  // Third page
```

```vb
' Default names are auto-generated
xpTaskPage1.LayoutName = "Card1"  ' First page
xpTaskPage2.LayoutName = "Card2"  ' Second page
xpTaskPage3.LayoutName = "Card3"  ' Third page
```

**LayoutName Purpose:**
- Unique identifier for each page
- Used internally by SelectedPage property
- Auto-generated by default (Card1, Card2, etc.)
- Can be customized for clarity

**Set Custom LayoutName:**

```csharp
xpTaskPage1.LayoutName = "GeneralSettings";
xpTaskPage2.LayoutName = "AppearanceSettings";
xpTaskPage3.LayoutName = "AdvancedSettings";
```

## SelectedPage Property

Access and control the currently active page:

**Get Selected Page:**

```csharp
// Get the currently visible page
XPTaskPage currentPage = xpTaskPane1.SelectedPage;
string pageName = currentPage.LayoutName;
string pageTitle = currentPage.Title;
```

**Set Selected Page:**

```csharp
// Switch to a different page programmatically
xpTaskPane1.SelectedPage = xpTaskPage2;
```

```vb
' Switch to a different page programmatically
xpTaskPane1.SelectedPage = xpTaskPage2
```

**Use Case: Page Selection on Event**

```csharp
// Navigate to page when user clicks button
private void btnGotoPage2_Click(object sender, EventArgs e)
{
    xpTaskPane1.SelectedPage = xpTaskPage2;
}
```

## Adding Pages Dynamically

Add pages at runtime in response to application logic:

```csharp
// Create new page dynamically
XPTaskPage newPage = new XPTaskPage();
newPage.Title = "Dynamic Page " + (xpTaskPane1.TaskPages.Length + 1);

// Add to container
wizardContainer1.Controls.Add(newPage);

// Update TaskPages collection
List<XPTaskPage> pageList = new List<XPTaskPage>(xpTaskPane1.TaskPages);
pageList.Add(newPage);
xpTaskPane1.TaskPages = pageList.ToArray();
```

**Dynamic Page Scenario:**

```csharp
public void AddTaskCategory(string categoryName)
{
    XPTaskPage newPage = new XPTaskPage();
    newPage.Title = categoryName;
    newPage.LayoutName = categoryName.Replace(" ", "");

    // Add container for page
    wizardContainer1.Controls.Add(newPage);

    // Add to TaskPages
    var pages = new List<XPTaskPage>(xpTaskPane1.TaskPages);
    pages.Add(newPage);
    xpTaskPane1.TaskPages = pages.ToArray();
}

// Call from application
AddTaskCategory("Reports");
AddTaskCategory("Analytics");
AddTaskCategory("Settings");
```

## Removing Pages

Remove pages from the XPTaskPane at runtime:

**Method 1: Update TaskPages Collection**

```csharp
// Remove specific page from TaskPages array
List<XPTaskPage> pageList = new List<XPTaskPage>(xpTaskPane1.TaskPages);
pageList.Remove(xpTaskPage2);
xpTaskPane1.TaskPages = pageList.ToArray();

// Also remove from container
wizardContainer1.Controls.Remove(xpTaskPage2);
xpTaskPage2.Dispose();
```

**Method 2: Clear and Rebuild**

```csharp
// Remove all pages
xpTaskPane1.TaskPages = new XPTaskPage[] { };
wizardContainer1.Controls.Clear();

// Re-add selected pages
XPTaskPage keepPage1 = new XPTaskPage() { Title = "Page 1" };
wizardContainer1.Controls.Add(keepPage1);
xpTaskPane1.TaskPages = new XPTaskPage[] { keepPage1 };
```

**Removal Best Practices:**
- Remove from TaskPages array
- Remove from WizardContainer.Controls
- Call Dispose() to free resources
- Re-assign TaskPages to reflect changes

## Adding Controls to Pages

Each task page is a container that can host any Windows Forms control:

**Example: Add Multiple Controls to a Page**

```csharp
XPTaskPage settingsPage = new XPTaskPage();
settingsPage.Title = "Settings";

// Create controls
Label lblName = new Label();
lblName.Text = "Application Name:";
lblName.Location = new Point(10, 10);
lblName.AutoSize = true;

TextBox txtName = new TextBox();
txtName.Location = new Point(10, 30);
txtName.Width = 200;

Button btnSave = new Button();
btnSave.Text = "Save";
btnSave.Location = new Point(10, 60);

// Add controls to page
settingsPage.Controls.Add(lblName);
settingsPage.Controls.Add(txtName);
settingsPage.Controls.Add(btnSave);

// Add page to container
wizardContainer1.Controls.Add(settingsPage);
```

**Complex Page Layout Using Panels:**

```csharp
// Create main panel for organization
Panel mainPanel = new Panel();
mainPanel.Dock = DockStyle.Fill;

// Create sub-panels for sections
Panel configSection = new Panel();
configSection.Height = 100;
configSection.Dock = DockStyle.Top;

Panel dataSection = new Panel();
dataSection.Dock = DockStyle.Fill;

// Add controls to sections
Label lblConfig = new Label() { Text = "Configuration" };
configSection.Controls.Add(lblConfig);

// Add sections to main panel
mainPanel.Controls.Add(dataSection);
mainPanel.Controls.Add(configSection);

// Add panel to page
settingsPage.Controls.Add(mainPanel);
```

**Data Grid in Task Page:**

```csharp
// Create grid control
DataGridView grid = new DataGridView();
grid.Dock = DockStyle.Fill;
grid.AutoGenerateColumns = true;
grid.DataSource = GetData(); // Populate from data source

// Add to page
dataPage.Controls.Add(grid);
```

## Page Control Access and Manipulation

Access controls within a page:

```csharp
// Get all controls in a page
foreach (Control ctrl in xpTaskPage1.Controls)
{
    Console.WriteLine(ctrl.Name + ": " + ctrl.GetType().Name);
}

// Find specific control
Control foundControl = xpTaskPage1.Controls.Cast<Control>()
    .FirstOrDefault(c => c.Name == "btnSubmit");

// Get nested control
TextBox txt = xpTaskPage1.Controls.Find("textInput", true)
    .FirstOrDefault() as TextBox;
```

## Common Page Management Issues

**Issue: New pages not showing**
- Verify page added to WizardContainer.Controls
- Verify TaskPages array includes new page
- Set SelectedPage to new page if not visible

**Issue: Cannot remove page**
- Ensure page is not currently selected
- Switch SelectedPage before removal
- Check disposal and collection update order

**Issue: Controls not visible in page**
- Set control Location and Size (or use Dock/Anchor)
- Verify control added to page.Controls collection
- Check page is in active/visible state
